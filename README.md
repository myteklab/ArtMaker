# Art Maker

A kaleidoscope you draw into. Draw one line and it repeats around the center, mirrored, in any color, so a scribble turns into a mandala. Change the number of folds, switch on Rainbow, and the symmetry does the rest.

**Try it in your browser, no account needed:** [mytekdev.com/tools/art-maker](https://mytekdev.com/tools/art-maker). The page has a live demo and explains what students learn from it.
